# Lole Enterprise Departmental Registry

This registry defines the 23 granular departments of the Lole Enterprise Platform. Each unit is owned by a specialized autonomous agent lead.

---

## I. Platform Engineering (The Machinery)

### 1. Core Runtime & Gateway

- **ID**: `core-runtime`
- **Lead**: RuntimeAgent
- **Mission**: Ensure the "Store Brain" (Gateway) is invincible. Manage local bus (MQTT) and local-first logic.

### 2. Mobile & Native (Capacitor)

- **ID**: `mobile-native`
- **Lead**: MobileAgent
- **Mission**: Maintain the high-performance Android APK and the bridge to native device hardware.

### 3. Sync & Persistence

- **ID**: `sync-persistence`
- **Lead**: SyncAgent
- **Mission**: Manage the PowerSync/Supabase data bridge and resolve "Split-Brain" conflicts.

### 4. Frontend Architecture

- **ID**: `frontend-arch`
- **Lead**: FrontendAgent
- **Mission**: Architect the Next.js App Router and ensure sub-second UI responsiveness.

### 5. Backend Infrastructure

- **ID**: `backend-infra`
- **Lead**: BackendAgent
- **Mission**: Manage Supabase migrations, Edge Functions, and enterprise API contracts.
