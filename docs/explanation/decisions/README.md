## What is an ADR?

An Architecture Decision Record (ADR) is a document that captures a single architectural decision, including:

- The context and problem statement
- The decision made
- The consequences of the decision

## Creating New ADRs

Use the naming convention: `[NNN]-[brief-description].md` where NNN is a sequential number.
